# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good faith, criticise ideas and code rather than people, and keep
discussion about the work. Harassment of any kind is not tolerated.

To report behaviour that breaks it, contact the maintainer privately through GitHub (a private
security advisory on the repository reaches them directly). Reports are kept confidential.
